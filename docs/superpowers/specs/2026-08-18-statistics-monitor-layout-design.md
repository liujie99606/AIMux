# 数据统计与监控管理布局优化设计

## 目标

优化两个已有页面的桌面端信息密度与横向浏览体验：数据统计页把“总计、昨日、今日”从纵向大卡片调整为三行指标卡片；监控管理页横向滚动时固定“账号”列。

## 设计

- `StatisticsPage.vue` 保留现有 `groups`、`metrics`、数据加载和格式化逻辑，只调整摘要区模板和样式。
- 摘要区每个时间分组占一行，左侧显示分组标题，右侧按“总Token、总输入、总输出、总缓存、缓存率”展示五个独立卡片；指标卡片继续使用现有浅色边框、8px 圆角和紧凑桌面布局。
- 在较窄窗口中，指标卡片允许换行，时间分组标题保持独立列，避免内容溢出。
- `MonitorPage.vue` 的“账号”列设置 Element Plus `fixed="left"`，其余列和现有横向滚动宽度不变。

## 数据与交互

不改变 API、Pinia 状态或页面加载流程；空值和缓存率格式化规则沿用现有实现。

## 验证

运行 `npm run format:check` 和 `npm run build`，确认 Vue 模板、TypeScript 和 CSS 构建通过。
