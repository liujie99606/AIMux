# AIMux 功能清单

## 网关和调度

- 本地启动 FastAPI 兼容网关，默认地址为 `http://127.0.0.1:7788`。
- 支持 OpenAI 和 Anthropic 两套原生协议，按协议隔离账号，不做协议转换。
- 支持非流式和 SSE 流式转发。
- 每次上游失败按最新优先级重新选择账号并重试，重试次数是单次客户端请求的总尝试上限，默认 10 次，可设置为 1 至 20 次。
- 真实请求成功使账号优先级加 1，失败使优先级减 1，范围限制为 0 至 9。
- 每次上游尝试单独写入使用记录，并共享同一个 `trace_id`。

## 账号管理

- 新增、编辑、复制、删除账号。
- 维护协议类型、上游地址、API 密钥、优先级、支持模型、标签和备注。
- 启用/停用账号；停用是人工状态，不会被测试结果自动改变。
- 账号列表按启用状态、优先级、名称和 ID 排序，支持类型和状态筛选。
- 支持单个测试和同协议账号批量测试，测试结果在统一弹窗中逐项显示。
- 支持全选、取消全选、在线编辑名称和优先级，以及优先级快捷加减 4。

## 使用记录

- 按账号 ID、模型、协议类型、成功/失败、开始时间和结束时间筛选。
- 默认每页查询 20 条，按开始时间倒序分页。
- 展示请求数、成功率和平均耗时三个当前页统计。
- 展示失败颜色、首 Token 用时、总耗时、推理强度和尝试次数。
- 可打开详情查看 trace、账号、状态码、错误信息、Token 和客户端 IP 等字段。
- 重置按钮清空筛选条件并从第一页重新查询。

## 模型维护

- 查看、新增、编辑、删除模型目录。
- 按 OpenAI/Anthropic 类型筛选。
- 每个协议类型可设置一个测试默认模型；删除或切换默认模型时自动补齐该类型默认项。
- 账号表单和连接测试只展示当前协议类型的模型。

## 设置

- 设置监听地址、端口、数据库路径。
- 设置上游整体超时、首字超时和单次请求总尝试次数。
- 设置管理 API 使用的本地令牌。
- 设置 Windows/macOS 开机自启。
- 保存后客户端立即更新本地令牌；监听地址、端口和数据库路径下次启动生效。
