# AIMux 功能清单

## 网关和调度

- Rust/Axum 本地兼容网关，稳定地址为 `http://127.0.0.1:7789`。
- 支持 OpenAI 和 Anthropic 两套原生协议，按协议隔离账号，不做协议转换。
- 支持非流式和 SSE 流式转发，原样保留请求内容和协议语义。
- 每次上游失败按最新优先级重新选择账号并重试；重试次数是单次客户端请求的总尝试上限，默认 10 次。
- 真实请求成功使账号优先级加 1，失败使优先级减 1，范围为 0 至 9。
- 每次上游尝试单独写入使用记录，并共享同一个 `trace_id`。

## 账号管理

- 新增、编辑、复制和删除账号。
- 维护协议类型、上游地址、API 密钥、倍率、优先级、支持模型、标签和备注。
- 状态列可直接启用/禁用账号；禁用是人工状态，不会被测试结果自动替换。
- 列表支持类型和状态筛选，并按启用状态、优先级、倍率、名称和 ID 稳定排序。
- 支持单个测试和同协议账号批量测试，使用统一测试弹窗。
- 支持模型映射，将客户端模型映射为当前账号上游模型。

## 使用记录

- 按账号、模型、协议、成功/失败、开始时间和结束时间筛选。
- 默认每页查询 10 条，按开始时间倒序分页。
- 展示当前页请求数、成功率和平均耗时。
- 失败记录显示失败原因；详情展示请求、账号、状态码、错误信息、Token 和客户端 IP。
- Token 用量展示输入、缓存、输出、合计和缓存率；首字耗时与总耗时合并为延迟列。
- 支持重置查询条件和清除 3 天以前的使用记录。

## 数据统计

- 展示总计、今日、昨日的总 Token、总输入、总输出、总缓存和缓存率。
- 展示启用账号的今日 Token 使用情况。
- Token 数量使用 `k`、`m` 等紧凑格式，缓存率按总缓存除以总输入计算。

## 模型维护

- 查看、新增、编辑和删除模型目录。
- 按 OpenAI/Anthropic 类型筛选。
- 账号支持模型、测试默认模型和模型映射候选来自对应协议类型的模型目录。

## 设置

- 左侧菜单显示本机动态时间。
- 配置监听端口、总尝试次数、首字超时、请求超时、监控开关和监控间隔。
- 配置是否启用上游代理及代理地址，默认 `http://127.0.0.1:7890`。
- 配置管理 API 使用的本地令牌。
- 打开数据目录、查看 GitHub、检查更新和复制 OpenAI/Anthropic 请求地址。
- 保存后可立即生效的运行时设置会在下一次请求读取；端口变化需要重启。

## 账号监控

- 后台任务启动后立即检查所有启用账号，之后每 2 分钟检查一轮。
- 每个账号使用对应协议的测试默认模型发送一次最小请求，测试模型遵循账号模型映射。
- 监控成功时优先级 0 至 5 加 1，6 至 9 保持不变；失败时减 1，最低为 0。
- 每轮按协议比较成功账号的倍率，低倍率成功账号可提升到优先级 9；调度取号按优先级降序、倍率升序。
- 监控结果独立保存，页面展示最近 30 次检测记录和平均耗时。
