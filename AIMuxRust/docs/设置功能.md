# 设置功能

## 1. 设置项

设置页面维护以下配置：

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 监听地址 | `127.0.0.1` | 本地 API 绑定地址 |
| 端口 | `7788` | 本地 API 监听端口，范围 1-65535 |
| 数据库路径 | 空 | 空值使用系统用户数据目录下的 SQLite；非空使用指定路径 |
| 上游超时（秒） | `300` | 非流式请求整体超时和流式读取超时，范围 1-3600 |
| 首字超时（秒） | `60` | 流式请求等待第一个响应块的超时，范围 1-3600 |
| 总尝试次数 | `10` | 一次客户端请求最多进行的上游尝试次数，范围 1-20 |
| 启用上游代理 | 关闭 | 是否对所有上游请求显式使用下方代理地址 |
| 上游代理地址 | `http://127.0.0.1:7890` | HTTP/HTTPS 代理地址，例如本机 Clash Verge 的混合端口 |
| 开启账号监控 | 开启 | 是否在后台每 2 分钟检查启用账号；关闭后不创建新监控记录 |
| 本地令牌 | 空 | 管理 API 和兼容 API 的 Bearer 认证令牌 |
| 开机自启 | 关闭 | 是否写入当前平台的开机启动配置 |

“总尝试次数”与账号无关。它限制的是一次请求的总尝试数；每次失败后仍按实时优先级重新选择账号，达到次数上限才返回最终失败。

## 2. 保存和生效

页面打开或切换到设置菜单时调用 `GET /api/settings` 加载最新值。保存时调用 `PUT /api/settings`，配置写入用户数据目录的 JSON 文件，并立即更新当前桌面端 `ApiClient` 使用的本地令牌。

设置页提供“打开数据目录”按钮，会使用系统文件管理器打开 AIMux 的用户数据目录。该目录包含配置文件、默认数据库和启动错误日志；如果数据库路径被自定义，数据库文件仍以设置中的路径为准。

监听地址、端口和数据库路径在当前进程中不重启服务，提示用户下次启动生效；上游超时、首字超时、总尝试次数和上游代理由后续请求读取最新服务设置，因此保存后下一次请求即可使用新值。开启代理时，AIMux 只对上游请求显式传入该地址；关闭时强制直连，不读取系统或环境代理。开机自启由平台适配模块更新，失败会以错误提示返回。

## 3. 配置加载优先级

启动时先读取配置文件，再应用同名 `AIMUX_*` 环境变量覆盖。支持的环境变量包括 `AIMUX_HOST`、`AIMUX_PORT`、`AIMUX_DB_PATH`、`AIMUX_UPSTREAM_TIMEOUT_SECONDS`、`AIMUX_FIRST_TOKEN_TIMEOUT_SECONDS`、`AIMUX_REQUEST_RETRY_ATTEMPTS`、`AIMUX_UPSTREAM_PROXY_ENABLED`、`AIMUX_UPSTREAM_PROXY_URL`、`AIMUX_MONITORING_ENABLED`、`AIMUX_LOCAL_TOKEN` 和 `AIMUX_LAUNCH_AT_LOGIN`。重试次数最终还会钳制到 1-20。
