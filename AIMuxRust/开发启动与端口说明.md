# AIMux Rust 开发启动与端口说明

## 端口分工

| 服务 | 端口 | 用途 | 数据库 |
| --- | ---: | --- | --- |
| 稳定网关 | `7789` | Codex 或其他客户端实际使用的接口 | `aimux.db` |
| 开发网关 | `7790` | 后端代码调试和接口验证 | `aimux.db` |
| Vite 前端 | `1420` | 日常页面开发和热更新 | 不适用 |

Rust 后端代码不能像 Vue 页面一样热更新。修改后端后需要重新编译或重启，但只重启 `7790` 开发网关，不触碰 `7789`，因此不会中断正在使用稳定网关的 Codex。

两个网关始终使用系统数据目录下同一个 `aimux.db`。数据库不按端口区分；旧配置文件里的自定义 `db_path` 不再生效。

日常只修改前端时，不要运行 `npm run tauri dev`。Tauri 开发模式会把窗口和 Rust 网关绑定在一起，不适合作为稳定接口使用。

需要调试桌面窗口时，使用项目提供的隔离命令 `npm run dev:desktop`，不要直接运行 `npm run tauri dev`。该命令会自动设置桌面开发环境使用 `7790`、共享 `aimux.db` 和关闭监控。

## 日常前端开发

首次进入项目或依赖发生变化时执行一次：

```powershell
cd E:\liujie\2026\github\juhe\AIMux\AIMuxRust
npm install
```

然后打开两个 PowerShell 窗口。

窗口一启动稳定网关。已构建过时直接运行即可：

也可以双击 `scripts/windows/start_rust_7789.bat` 启动稳定 Rust 网关。脚本窗口会保持打开。

```powershell
cd E:\liujie\2026\github\juhe\AIMux\AIMuxRust\src-tauri
.\target\debug\aimux-gateway.exe
```

如果提示找不到文件，先构建一次：

```powershell
cargo build --bin aimux-gateway
```

窗口二启动前端：

也可以双击 `scripts/windows/start_frontend.bat` 启动前端。脚本窗口会保持打开，并连接稳定 Rust 后端 `7789`。

```powershell
cd E:\liujie\2026\github\juhe\AIMux\AIMuxRust
npm run dev
```

浏览器访问 `http://127.0.0.1:1420`。前端页面保存后由 Vite 热更新，稳定网关不会重启。

如果要让前端连接开发后端 `7790`，不要使用 `start_frontend.bat`；请使用 `start_desktop.bat`，或在 PowerShell 中手动设置 `VITE_API_BASE` 后执行 `npm run dev`。

## 桌面端开发

先关闭单独运行的 `npm run dev`，然后执行：

```powershell
cd E:\liujie\2026\github\juhe\AIMux\AIMuxRust
npm run dev:desktop
```

也可以双击 `scripts/windows/start_desktop.bat`。脚本会同时启动 Vite 和 Tauri，窗口会保持打开。

该命令会同时启动 Vite 和 Tauri 桌面窗口。桌面窗口连接 `7790`，稳定网关 `7789` 不会被占用或重启。退出桌面开发时，在命令窗口按 `Ctrl+C`。

`start_desktop.bat` 已经同时启动前端，不要再重复运行 `start_frontend.bat`，否则会发生 `1420` 端口冲突。

## 后端代码开发

保持 `7789` 稳定网关继续运行，另开窗口执行：

后端开发网关也可以双击 `scripts/windows/start_rust.bat`，它使用 `7790` 和共享 `aimux.db`；不要把这两个脚本混淆。

```powershell
cd E:\liujie\2026\github\juhe\AIMux\AIMuxRust
npm run dev:gateway
```

该命令会：

- 在 `7790` 启动独立后端；
- 与 `7789` 共享同一个 `aimux.db`，开发端的账号修改会直接生效；
- 默认关闭账号监控，避免开发实例重复请求上游；
- 后端源码变化时只重新编译和重启开发实例。

如果要让前端调用开发网关，先停止普通的前端开发进程，在同一个窗口设置 API 地址后再启动：

```powershell
$env:VITE_API_BASE = 'http://127.0.0.1:7790'
npm run dev
```

调试结束后关闭该前端窗口，重新执行 `npm run dev` 即可恢复连接稳定网关 `7789`。

由于两个实例共享 SQLite 文件，请不要同时启动两个启用监控的实例；当前开发入口默认关闭监控，稳定网关按设置执行监控。

## 常见问题

### `Port 1420 is already in use`

说明已有 Vite 在运行。直接使用已经运行的 `http://127.0.0.1:1420`，或者切换到运行它的窗口按 `Ctrl+C` 后再执行 `npm run dev`。

### `7789` 无法访问

确认稳定网关窗口仍在运行，并检查：

```powershell
Invoke-RestMethod http://127.0.0.1:7789/health
```

正常结果为：

```json
{"status":"ok"}
```

### 查看日志

日志位于：

```text
C:\Users\<用户名>\AppData\Roaming\quietforge\AIMux\data\log
```

日志按日期生成，包含请求 URL、请求参数、响应状态和错误信息，不包含 API 密钥。
